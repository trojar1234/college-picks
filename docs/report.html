Backtest Historical · rebuilt from past results and lines

Walk-forward: each week is predicted using only data available before it, then graded against that week's lines. It approximates the live rules but can't replay everything (QB changes and weather alerts, or the exact lines available on the day), and these same seasons were used to choose the 7-point rule, so treat it as an upper bound. "Miss" = average points off (lower is better).

What each column means
  • Bets ATS vs open: games where the model and the opening spread were 7+ points apart, graded against that opening line (when the model's bets are meant to be placed).
  • Bets ATS vs close: the same rule against the closing line, the sharpest line of the week.
  • Bets O/U: the same for totals.
  • All games ATS vs close: the model's side in every game against the closing line, whatever the gap.
  • Approx. live rules: the opening-line bets that today's cautions would still allow (gap under 10, after week 3, no FCS teams).
  • Range: the 95% range for the true win rate given the number of settled bets (pushes excluded). It reflects luck only, not the extra optimism from choosing the rules on these seasons. The week-grouped range allows for bets in the same week moving together.
  • Small grey numbers after a record are pushes. Opening lines exist mostly from 2023 on.

Ranges: green = even the low end clears the 52.4% needed to profit at −110, amber = can't be told apart from break-even yet, red = below break-even.

An honest test of the 7-point rule

Choosing the threshold on the same seasons used to grade it flatters the result. Here each season is bet with whichever threshold (5–10 points) made the most units in the seasons before it, so no season helps pick its own rule.

Ideas tested earlier and dropped

None of these improved accuracy on seasons the model hadn't seen: weather at kickoff, travel and rest, recency weighting, run/pass matchups, fitting the margin directly, a diminishing-returns margin rating, per-team home field, coaching changes, turnover-based preseason weighting, star-rating-based recruiting/portal data, the expected starting QB as a model input (it stays an alert), separate prior strengths per stat, blending ratings with different prior strengths, a median-based (instead of average-based) points fit, a matchup-type totals correction, explosiveness, standard/passing-down efficiency, line yards and stuff rate, a QB adjustment only for new starters, a prior strength that changes through the season, a Power 4 vs Group of 5 margin adjustment, and a machine-learning (gradient-boosted) correction on top of the model. A separate totals model made totals more accurate but its flagged over/under bets did worse against opening lines, so it's off.
